Midnight Gallery is a 2D top-down stealth heist game. Sneak through a museum gallery at night, dodge patrolling guards and sweeping security cameras, pick the lock on the Star Sapphire's case, grab what you can, and slip out the south door before the alarm fills. No libraries, no network: the whole game is plain canvas JavaScript with synthesized WebAudio sound.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in a desktop browser
```

## Play

- WASD / arrows — move, Shift — sneak, E — grab loot / hold to pick the lock
- Q — throw a smoke bomb, M — mute, P — pause, R — retry after caught / win
